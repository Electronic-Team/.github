## Electronic Team

We build software for working with serial ports and USB devices: monitoring, virtualising and sharing them across machines and networks.

### Serial Agent Toolkit

Open agent skills that give AI coding agents (Claude Code, Cursor, GitHub Copilot, Codex, OpenCode and others) safe access to serial ports through our tools: capture traffic, build virtual test benches, and reach devices on other machines.

```bash
npx skills add Electronic-Team/serial-agent-toolkit
```

→ [Electronic-Team/serial-agent-toolkit](https://github.com/Electronic-Team/serial-agent-toolkit)

### Serial port tools

- [Serial Port Monitor](https://www.serial-port-monitor.org/?utm_source=github&utm_medium=org-profile&utm_campaign=serial-agent-toolkit): capture and analyse serial traffic, even on ports other apps already have open
- [Virtual Serial Port Driver](https://www.virtual-serial-port.org/?utm_source=github&utm_medium=org-profile&utm_campaign=serial-agent-toolkit): virtual COM port pairs, port sharing and splitting
- [Serial to Ethernet Connector](https://www.serial-over-ethernet.com/?utm_source=github&utm_medium=org-profile&utm_campaign=serial-agent-toolkit): share serial ports over the network, on Windows and Linux
